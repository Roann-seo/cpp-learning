### 1.3 STL 深入重点

| 容器 | 要搞懂 |
|:---|------|
| `vector` | 扩容机制（1.5x vs 2x）、`reserve` vs `resize`、内存不释放 |
| `string` | SSO 短字符串优化、COW 写时拷贝 |
| `map/set` | 红黑树实现、为什么不用 AVL |
| `unordered_map` | 哈希桶、rehash 时机、负载因子 |

### 1.4 现代 C++（C++11/14/17）— 面试必考

| 特性 | 面试频率 | 内容 |
|:---|:---:|------|
| 右值引用 & 移动语义 | ⭐⭐⭐⭐⭐ | `std::move`、移动构造、移动赋值 |
| 智能指针 | ⭐⭐⭐⭐⭐ | `unique_ptr`、`shared_ptr`（控制块）、`weak_ptr` |
| lambda 表达式 | ⭐⭐⭐⭐ | 捕获列表、`[=]` vs `[&]`、闭包 |
| auto / decltype | ⭐⭐⭐ | 类型推导 |
| nullptr | ⭐⭐ | 为什么不用 NULL |
| constexpr | ⭐⭐ | 编译期计算 |
| thread / mutex | ⭐⭐⭐⭐ | 简单多线程 |

### 1.5 内存管理（字节爱问）

```
栈 vs 堆 → new/delete 底层 → malloc/free → 内存对齐
→ 内存泄漏排查 → valgrind / AddressSanitizer
```

### 推荐项目：轻量级 Web 服务器（C++）

```
├── 线程池（生产者-消费者）
```

### 项目参考资源

- 怎么测试性能、优化瓶颈

## 核心要点

1. **C++ 不要只学语法** — 面试问 vector 扩容、shared_ptr 控制块、移动语义底层实现，问到源码级别
2. **在 Linux 上写代码** — 装虚拟机或 WSL2，环境切过去
3. **LeetCode 每天一道** — 一年 365 道，足够覆盖所有面试
4. **项目要能展开聊** — 面试官会追问为什么这么设计、遇到什么问题
