## 🧠 一、什么是图

| 概念 | 定义 | 例子 |
|------|------|------|
| **图 G = (V, E)** | V = 顶点集，E = 边集 | V={A,B,C}, E={(A,B),(B,C)} |
| **阶 n** | 顶点个数 | n = 3 |
| **边数 m** | 边的条数 | m = 2 |
| **无向图** | 边无方向 | (A,B) = (B,A) |
| **有向图** | 边有方向 | <A,B> ≠ <B,A> |

---

## 🔥 二、握手定理（必考填空）

> **所有顶点度数之和 = 2 × 边数**
>
> $$\sum_{v \in V} \deg(v) = 2m$$

| 推论 | 说明 |
|------|------|
| 奇度顶点个数必为**偶数** | 如果出现奇数个奇度顶点，这道题你一定算错了 |
| 有向图中 | 出度之和 = 入度之和 = 边数 |

### ✏️ 经典例题

> 已知图 G 有 5 个顶点，度数分别为 1, 2, 2, 3, 4，求边数。

**解**：$\sum\deg = 1+2+2+3+4 = 12$，$m = 12/2 = 6$ 条边 ✅

## 📊 三、图的分类

| 类型 | 定义 | 怎么记 |
|------|------|--------|
| **简单图** | 无平行边、无自环 | 最普通的图 |
| **完全图 Kₙ** | 每对顶点之间都有边 | n 个顶点的完全图有 $\frac{n(n-1)}{2}$ 条边 |
| **正则图** | 所有顶点度数相等 | 完全图就是 n-1 正则图 |
| **二分图** | 顶点分成两集合，边只跨集合 | 可以二染色 |

---

## 🔗 四、通路与回路

| 概念 | 含义 | 关键词 |
|------|------|--------|
| **通路** | 顶点-边交替序列 | 可以重复顶点 |
| **简单通路** | 顶点不重复 | "一笔画不回头" |
| **回路** | 起点=终点的通路 | 绕回来了 |
| **初级回路（圈）** | 除起点外顶点不重复 | 最简单的圈是 K₃（三角形） |

## 📐 五、图的矩阵表示（计算题常客）

### 5.1 邻接矩阵 A

> A[i][j] = 1 表示顶点 i 到 j **有边**，否则为 0

**核心结论**：

| 矩阵 | 含义 |
|------|------|
| A | 长度为 1 的通路数 |
| A² | 长度为 2 的通路数 |
| A³ | 长度为 3 的通路数 |
| Aⁿ[i][j] | 从 i 到 j 长度为 n 的通路总数 |

### ✏️ 例题

> 给定 3 个顶点的完全图 K₃，写出邻接矩阵 A，并求 A²，问长度为 2 的通路有几条？

**A**：
```
0 1 1
1 0 1
1 1 0
```

**A²**：
```
2 1 1
1 2 1
1 1 2
```

所有元素之和 = 12，即长度为 2 的通路共 **12 条** ✅

## ⚡ 六、常见坑

| ❌ 错误 | ✅ 正确 |
|--------|--------|
| 度数之和 = 边数 | 度数之和 = **2×** 边数 |
| 邻接矩阵 A² = A×2 | A² 是**矩阵乘法**，不是元素翻倍 |
| 完全图 Kₙ 有 n² 条边 | 完全图有 **n(n-1)/2** 条边 |
| 通路必须顶点不重复 | 通路可以重复，**简单通路**才不重复 |

---

## 📝 一句话总结

> 图 = 顶点 + 边。握手定理算边数，邻接矩阵算通路。两类图要分清：欧拉看边，哈密顿看顶点。
