三、计算题

19. 刚体转动 + 牛顿定律
──────────────────
设 m₁ 向下为正，加速度均为 a。

对 m₁：  m₁g - T₁ = m₁a          ……(1)
对 m₂：  T₂ - m₂g = m₂a          ……(2)
对滑轮：(T₁ - T₂)R = Jα          ……(3)
运动关联：a = Rα                  ……(4)

由(4)：α = a/R 代入(3)：
   T₁ - T₂ = Ja/R²                ……(5)

(1)+(2)：m₁g - m₂g - (T₁-T₂) = (m₁+m₂)a

代入(5)：g(m₁-m₂) - Ja/R² = (m₁+m₂)a

解得：a = (m₁-m₂)g / (m₁+m₂+J/R²)
       = (1.0×9.8) / (3.0 + 0.5/0.04)
       = 9.8 / 15.5
       ≈ 0.63 m/s²

T₁ = m₁(g-a) = 2.0 × (9.8-0.63) ≈ 18.3 N
T₂ = m₂(g+a) = 1.0 × (9.8+0.63) ≈ 10.4 N

20. 高斯定理
──────────────────
由球对称性，取半径为 r 的同心球面为高斯面。

(1) r < R（球体内）：
    先求高斯面内电荷：
    q_内 = ∫(0→r) Ar·4πr²dr = 4πA·[r⁴/4](0→r) = πAr⁴

    高斯定理：E·4πr² = πAr⁴/ε₀
    ∴ E = Ar²/(4ε₀)，方向沿径向向外

(2) r > R（球体外）：
    总电荷 q_总 = πAR⁴

    高斯定理：E·4πr² = πAR⁴/ε₀
    ∴ E = AR⁴/(4ε₀r²)，方向沿径向向外

    等效于全部电荷集中在球心产生的电场。

------------------------------------------------

21. 波动方程
──────────────────
已知：u = 20 m/s, A = 0.04 m, ν = 5 Hz
角频率 ω = 2πν = 10π rad/s

(1) x=0 处，t=0 时在平衡位置向 y 负方向运动：
    由旋转矢量法 → 初相 φ₀ = π/2（即 0 时刻在平衡点朝负向）
    振动方程：y₀ = 0.04cos(10πt + π/2) m
    或写作：y₀ = -0.04sin(10πt) m

(2) 波函数（沿 x 正方向传播）：
    y = 0.04cos[10π(t - x/20) + π/2]
      = 0.04cos(10πt - (π/2)x + π/2) m

(3) x = 2 m 处：
    y = 0.04cos(10πt - π + π/2)
      = 0.04cos(10πt - π/2) m
    或 y = 0.04sin(10πt) m

------------------------------------------------

22. 光栅衍射
──────────────────
已知：λ = 600 nm = 6.0×10⁻⁷ m, k=2 时 θ = 30°, 第3级缺级

(1) 光栅方程 d·sinθ = kλ：
    d = kλ/sinθ = (2×6.0×10⁻⁷)/sin30° = 12×10⁻⁷/0.5 = 2.4×10⁻⁶ m
    即 d = 2400 nm = 2.4 μm

(2) 缺级条件：第3级缺级 → d/b = 3
    ∴ b = d/3 = 0.8 μm = 800 nm

(3) |sinθ| ≤ 1，由 d·sinθ = kλ：
    |k|max < d/λ = 2400/600 = 4
    即 k 可取 0, ±1, ±2, ±3
    但 k = ±3 是缺级，看不到！
    实际可观察：k = 0, ±1, ±2, ±4
    （k=±4 刚好在 sinθ=1 处，理论可见）
